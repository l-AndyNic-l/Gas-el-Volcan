# Gas El Volcán

## 1. Descripción del proyecto

**Gas El Volcán** es un sitio web orientado a la comercialización y presentación de cilindros de gas licuado de petróleo (GLP). El proyecto permite a los usuarios conocer la empresa, revisar un catálogo de productos, consultar el detalle de los cilindros disponibles y acceder a funcionalidades básicas de registro, inicio de sesión y carrito de compras.

El sitio fue desarrollado como una aplicación web estática utilizando tecnologías fundamentales del desarrollo Front-End, incorporando HTML5, CSS3 y JavaScript para la estructura, diseño e interacción de sus diferentes módulos.

## 2. Objetivo

El objetivo principal del proyecto es desarrollar una interfaz web clara, funcional y adaptable que permita representar digitalmente los servicios de **Gas El Volcán**, facilitando la consulta de productos y entregando una experiencia de navegación sencilla para los usuarios.

Entre los objetivos específicos se encuentran:

- Presentar información general de la empresa.
- Mostrar un catálogo de cilindros de gas.
- Permitir filtrar productos por marca y capacidad.
- Mostrar información detallada de cada producto.
- Incorporar formularios de registro e inicio de sesión.
- Implementar validaciones mediante JavaScript.
- Mantener una estructura organizada de archivos y recursos.

## 3. Tecnologías utilizadas

| Tecnología | Uso |
|---|---|
| **HTML5** | Estructura y contenido de las páginas web. |
| **CSS3** | Diseño, estilos, distribución y presentación visual. |
| **JavaScript** | Validaciones, filtros, interacción y funcionalidades dinámicas. |
| **Font Awesome** | Incorporación de iconos en la interfaz. |
| **Git** | Control de versiones del proyecto. |
